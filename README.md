# Aimee Badminton AI

纯 Android 本地羽毛球辅助记分项目，目标设备：OPPO Find X6 Pro（骁龙 8 Gen 2 / 16GB）。

## 当前里程碑

### M1：摄像头采集基准
- CameraX 后置摄像头预览与实时图像分析
- 1280×720 分析分辨率请求（设备/相机组合可能协商为其他尺寸）
- FPS、帧尺寸、Java Heap、系统热状态展示
- 默认收起诊断信息，适合三脚架固定拍摄
- 不上传视频、不调用云端推理

### M2 基础模块：标准场地与计分规则
- 内置标准羽毛球场尺寸（单打边线、双打边线、发球线等）
- 单打 21 分制规则引擎：每球得分、两分领先、30 分封顶
- 视觉事件尚未接入得分引擎；不能把当前版本描述为已实现 AI 自动判分

## AI 自动判分的实现路径
1. 通过标准场地线自动标定摄像头视角（不要求用户手工测量场馆尺寸）
2. 本地 TrackNet 系列模型追踪羽毛球
3. 人体/击球事件识别与轨迹时序分析
4. 仅在高置信度回合结束时提交得分事件；低置信度时不擅自改分
5. Android 本地语音播报与比分展示

标准场地尺寸只是自动标定的先验，不代表任意机位无需视觉校准。球场线被遮挡、画面不完整或严重畸变时，识别可靠性会下降。

## 构建
GitHub Actions 会在推送到 main 或手动触发时构建 Debug APK，并上传构建产物。

## 当前限制
M1 是摄像头性能测试版本。虽然标准场地数据和计分规则引擎已加入工程，但羽毛球视觉模型、自动回合判断和自动记分闭环尚未完成。安装 M1 不会自动判断得分。
